# 천안시 청년정책 웹 프레젠테이션 (시안)

## 구성
- `index.html`: 반응형 프레젠테이션, CSS 및 JavaScript 포함
- `assets/autumn-play.gif`: 사용자가 새로 첨부한 GIF (표지와 7번째 슬라이드에 삽입, 움직임 유지)

## 실행
`index.html`을 브라우저에서 열면 됩니다. 별도의 빌드 과정이나 서버가 필요하지 않습니다.

## GitHub Pages
1. 저장소를 생성하고 이 폴더의 `index.html`, `assets/` 폴더를 저장소 루트에 올립니다.
2. GitHub 저장소 → Settings → Pages → Build and deployment → Deploy from a branch를 선택합니다.
3. `main` 브랜치와 `/(root)`를 선택해 저장합니다.
4. Pages에 표시된 주소로 접속합니다.

## 조작
- 상단 메뉴 또는 오른쪽 아래 이전·다음 버튼
- 키보드 방향키, Page Up/Down, Home/End, Space
- 모바일 좌우 스와이프 및 마우스 휠
- `G` 또는 상단 ☷ 버튼: 전체 슬라이드 보기

## 중요
현재 메시지에 실제 PPT/PDF 슬라이드는 없고 GIF 한 개만 첨부되어 있습니다. 따라서 이 문서는 원본 슬라이드 충실 변환본이 아니라 편집 가능한 7장짜리 웹 시안입니다. 청년정책의 공식 사업명/수치/성과는 추정하지 않았습니다. 실제 원본을 받으면 구성, 문구, 차트 등으로 교체해야 합니다.
